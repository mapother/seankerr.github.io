# seankerr.ai — v1

A static, black-and-white editorial homepage for Sean Kerr.

## Files
- `index.html` — homepage
- `styles.css` — typography-first responsive styling
- `img/sean-kerr.png` — portrait used in the About section
- `CNAME` — GitHub Pages custom domain configuration

## Deployment
Replace the corresponding files in the existing GitHub Pages repository. Keep the `img` folder structure intact.
